# MSG GBH Ninja Kitten Team

Dieses Repository ist der Projektarbeitsraum des Remote-Teams in Buzz.

Aufträge entstehen im passenden Buzz-Projekt und Ursprungsthread. Der Thread
nennt Ergebnis, Scope, Grenzen und ein überprüfbares Fertig-Kriterium. Der
direkt adressierte Lead delegiert nur die kleinste notwendige Arbeitszelle und
fasst Ergebnis, Evidenz sowie offene Punkte wieder im Ursprungsthread zusammen.

Dieses Repository enthält Projektarbeit. Die Buzz- und VPS-Konfiguration liegt
getrennt im Verwaltungsrepository und gehört nicht in diesen Arbeitsraum.
